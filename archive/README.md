# Archive

The original interactive lecture-note pages (with the live floating-point
number-line widgets, sliders, and full KaTeX-rendered math) as originally
authored. These are large, self-contained HTML files with embedded fonts.

The site's `notes/lecture-01.html` and `notes/lecture-02.html` are a
lighter-weight, site-styled rewrite of the same content for browsing
alongside the rest of the course site. Link to a file in this folder
directly if you want students to see the original interactive version.
