1. Floating-point systems

A floating-point system is specified by F(β,p,L,U)\mathbb{F}(\beta,p,L,U)F(β,p,L,U). A normalized nonzero number can be written as

where d0≠0d_0\ne 0d0​=0 and each digit satisfies di∈{0,1,…,β−1}d_i\in\{0,1,\ldots,\beta-1\}di​∈{0,1,…,β−1}.

The spacing between representable numbers is not constant. There are the same significand patterns at each exponent, so the absolute spacing increases with magnitude.

2. Representation error and machine precision

For a real number x∈Rx\in\mathbb{R}x∈R inside the representable range, there is a unique floating-point approximation x^\hat{x}x^ satisfying

∃! x^∈Fs.t.∣x−x^∣≤εmachine∣x∣.\exists!\,\hat{x}\in\mathbb{F}\quad\text{s.t.}\quad |x-\hat{x}|\le \varepsilon_{\mathrm{machine}}|x|.∃!x^∈Fs.t.∣x−x^∣≤εmachine​∣x∣.

This representation error is also called round-off error: xxx is rounded up or down to a nearby representable value.

εmachine=β1−p.\varepsilon_{\mathrm{machine}}=\beta^{1-p}.εmachine​=β1−p.

The smallest positive normalized number is instead

xmin⁡=βL.x_{\min}=\beta^L.xmin​=βL.

Machine precision and the smallest positive representable number describe different limitations. The first controls relative spacing; the second is set by the lower exponent bound.

4. Catastrophic cancellation and associativity

Take six significant decimal digits and

a=1.23456×102,b=−1.23455×102,c=−1.11123×10−3.a=1.23456\times10^2,\qquad b=-1.23455\times10^2,\qquad c=-1.11123\times10^{-3}.a=1.23456×102,b=−1.23455×102,c=−1.11123×10−3.

Over the real numbers,

(a+b)+c=a+(b+c).(a+b)+c=a+(b+c).(a+b)+c=a+(b+c).

With finite precision, the two evaluation orders need not agree. Nearly cancelling numbers can erase significant digits, and subsequent arithmetic proceeds from the rounded intermediate result.

Numerical diagnostic

Evaluate the same mathematical quantity using more than one reasonable association pattern: direct summation, chunks of 500, chunks of 1,000, chunks of 10,000, and so on. If the answers vary substantially, the numerical result is algorithm-dependent and should not be treated as a reliable approximation.

Why “the sum stopped changing” does not prove convergence

A genuinely convergent sequence and a finite-precision sequence whose increments have become too small can both appear constant. Detecting Si+1=SiS_{i+1}=S_iSi+1​=Si​ identifies a machine limitation, but by itself it does not distinguish mathematical convergence from numerical stagnation.

8. Main takeaways

  • Floating-point arithmetic operates on a finite set of numbers.
  • Representable range and machine precision are separate properties.
  • Absolute spacing grows with magnitude even when the relative precision is fixed.
  • Catastrophic cancellation can remove significant digits.
  • Floating-point addition is not reliably associative.
  • Algebraically equivalent formulas can have very different numerical behavior.
  • Changing the summation order is a useful stress test when the exact answer is unknown.
